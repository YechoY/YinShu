### §1.4 api.py 路由收敛（唯一有顺序风险的一步）

4 条泛型路由，**必须放在所有 `/api/*` 路由定义之后**（就用现在 1816 的位置）、且**必须**在 `webdav_fallback`(`:2093`) 之前。骨架：

```python
def _dialect_or_404(root: str, file: str):
    d = adapters.dialect_for_path(root, file)
    return d, (None if d is not None else JSONResponse({"error": "not found"}, status_code=404))

@app.get("/d/{device}/{root}/{file}")
def get_webdav_dev(device: str, root: str, file: str, authorization: str = Header(default=""),
                   if_none_match: str = Header(default=""),
                   x_hub_device: str = Header(default="")) -> Response:
    d, err = _dialect_or_404(root, file)
    if err is not None:
        return err                      # 未注册路径 → 与今天 webdav_fallback 的 404 同体
    dev, derr = _resolve_device(device, x_hub_device)
    if derr is not None:
        return derr                     # 注册路径 + 非法设备 → 400（不变）
    return _sync_get(d.name, authorization, if_none_match, device=dev)

@app.put("/d/{device}/{root}/{file}")   # 同上，转 _sync_put
@app.get("/{root}/{file}")              # 无设备版，_resolve_device(None, x_hub_device)
@app.put("/{root}/{file}")
```

## §2 任务包 B：邀请码清理（用户选定 B 方案）

### §2.1 问题

撤销是**软撤销**：`src/hub/api.py:1237-1253 api_invite_revoke` 只写 `inv["disabled"] = True` + `_persist_config()`，**永不删除条目**，代码里**没有任何 GC 路径**。于是 `config.json` 里 7 条邀请码全部失效却永久占位（6 条 `disabled:true` + 1 条已用完）。失效码**没有安全风险**（用码前必过 `src/hub/api.py:435-446 _invite_status`，一律拒绝），纯粹是"占位 + 用户看着疑惑"。

### §2.2 后端：`POST /api/invites/prune`

放在 `api_invite_revoke`(`:1237-1253`) 之后，权限逻辑**精确对齐 revoke**（创建者本人 / 空间 owner），**不允许**普通 editor 清掉别人建的码：

```python
@app.post("/api/invites/prune")
async def api_invite_prune(request: Request, authorization: str = Header(default="")) -> JSONResponse:
    """清理已失效（撤销/过期/用完）的邀请码。owner 清本空间全部；editor 只清自己创建的。"""
    user = _auth_user(authorization)
    if user is None: return _unauthorized()
    body = await _json_body(request)                 # 用文件里既有的取 body 方式
    sp = str(body.get("space") or "") or _space_of(user)
    sp = _find_space(sp) or sp
    role = _role_in(user, sp)
    if role is None: return JSONResponse({"error": "你不是该空间成员"}, status_code=403)
    if role not in ("owner", "editor"):
        return JSONResponse({"error": "只读成员无权清理邀请码"}, status_code=403)
    is_owner = role == "owner"
    removed = []
    for code, inv in list(_invites.items()):
        if inv.get("space") != sp: continue
        if not is_owner and inv.get("created_by") != user: continue
        if _invite_status(inv) is None: continue      # 仍有效 → 保留
        del _invites[code]; removed.append(code)
    if removed:
        _persist_config()
        _audit("invite.prune", user, sp, f"清理失效邀请码 {len(removed)} 条")
        _log(f"邀请码: {user} 在空间 {sp} 清理失效码 {len(removed)} 条")
    return JSONResponse({"ok": True, "space": sp, "removed": len(removed), "codes": removed})
```

要求：**幂等**（无可清理项返回 200 `removed:0`）、**不删有效码**、**不动别的空间**、只软删（本操作就是物理删，因为条目已确定无效）。
