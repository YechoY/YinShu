# 14 · 洛雪接入（`lx-x` 方言）

> 洛雪音乐（lx 系）通过 WebDAV 同步歌单。2026-10-07 为其实现 `lx-x` 适配器，枢纽能收它的整份 `playlists.json`、做三路合并、按原形回写。
> 对应代码：`src/hub/adapters/lx.py` + 测试 `tests/hub/test_adapters_lx.py`（8 条全绿）。

## 14.1 洛雪文件长什么样（真机样本）

- 目录：云盘 `LX_Muisc/`（洛雪代码里目录名可配；枢纽文件名兜底 `playlists.json` 与 `lx-x-playlists.json` 都能命中，目录名写错成 `LX_Muisc` 也能用）。
- 顶层：`version`（字符串 `"2"`）、`data`（四键 `defaultList / loveList / tempList / userList`）、`playHistory`、`downloadTasks`、`lastModified`（epoch 毫秒整数）。
- 真机分布（2026-10 样本，`tests/data/lx_playlists_full.json`，共 **1386 首** = **tx 1169 : wy 69 : kg 49 : kw 99**）：
  - `userList`：用户自建歌单（YHK 114 首 / 纯音乐 17 首，全 tx 源）——**只有这部分参与合并**；
  - `defaultList` 722（wy54/tx540/kg39/kw89）、`loveList` 232（tx197/wy15/kg10/kw10）、`tempList` 301（tx301）——**按客户端分桶 opaque，不合并、不跨设备**。
- 曲目字段：顶层 `id`（形如 `wy_xxx` / `tx_xxx`，**老格式可能无前缀**如 `545879713_E3426FF...`）、`source`、`name`、`singer`、`interval`（`mm:ss`）、`meta`（`strMediaMid` / `songId` / `songmid` / `hash` / `copyrightId` / `albumName` / `albumId` 等）；少数曲目另有 `alias` / `artists`。**顶层没有 `album` 键**——专辑名在 `meta.albumName`。
- 附加键：`origin` / `sourceListId` / `locationUpdateTime` 原样透传；枢纽新建歌单给 `origin="created"`、`locationUpdateTime=null`。

## 14.2 身份规则（`_resolve_lx_identity`）

| 场景 | 身份键 | 说明 |
|---|---|---|
| 顶层 id 带 `<source>_` 前缀 | `platform_id = id 去前缀`，`source = song.source` | 标准 |
| 顶层 id 无前缀（kg 老格式等） | 退 `meta.strMediaMid` → `songId` → `songmid` → `hash` → `copyrightId` | 缺失才逐级退 |
| `source` 缺失 | 取 `meta` 里能猜到的源 | —— |
| 非白名单音源（非 wy/tx/kw/kg/mg）或**仍无法定身份** | 整首进 `opaque["tracks"][歌单id]` | 不参与合并判定与去重、不跨设备下发 |
| `meta.id == 0` | 不写 `lx_num_id` | 原样保留 0 |

**回写字段**（`meta_delta`，缺失字段不覆盖已有值）：`title / singer / album / duration_ms / quality / pic_url` + 洛雪回写字段 `lx_native_id`（原样 id，优先）/ `lx_num_id`（id≠0 才写）/ `lx_str_media_mid` / `lx_song_id`。

## 14.3 合并与旁路边界

- **参与合并**：`data.userList`（用户自建歌单）——洛雪方言 `capabilities = {delete_track: True, delete_playlist: True, create_playlist: True, reorder: False}`。
- **整文件旁路**（`bypass_files = ("settings.json", "user_apis.json")`）：原样收进 `opaque_by_client[cid]["lx_blobs"][文件]`、原样还；PUT 无则 404（洛雪按"云端未找到"处理）。
- **分桶保管**：`defaultList / loveList / tempList`、顶层 `playHistory` / `downloadTasks` → `opaque` 按客户端分桶，**不会被别人清空，也不会发给别人**。
- **渲染外形**：`version` 字符串 `"2"`、`lastModified` epoch 毫秒整数、`interval` 用 `mm:ss`（>1h 用 `h:mm:ss`）、`meta.id` 原样回写（为 0 也是 0）、曲目 `id` 原样字符串；"别的客户端带进来的新歌"才合成 `"<source>_<id>"`。

## 14.4 洛雪侧要配合的事

1. **请求头 `X-Hub-Device: <设备名>`**（首选；`src/utils/webdav.ts:20` 一处）；或地址填 `http://<枢纽>:8000/d/<设备名>`、目录填 `lx-x`（兜底，二选一别叠加）。
2. **`playHistory` / `downloadTasks` 保持回还一致**：枢纽按客户端分桶原样还，若两者对不上会被判成"每次都有本地改动"而反复上传。
3. **`version` / 曲目 `id` / `interval` 保持现状**：均原样回写，不改写、不重算。
4. 洛雪 `webdav@5.8.0` 的 `ensureDirectoryExists()` 依赖 `stat`（PROPFIND）——枢纽已补最小合法 **207 multistatus**（`src/hub/api.py` 的 `webdav_propfind`，`OPTIONS` 的 `Allow` 已含 `PROPFIND`）。缺它会拿到 405，而该库的 `exists()` 只把 404 当"不存在"、其它错误照抛 ⇒ 上传直接失败。

## 14.5 测试证据（`tests/hub/test_adapters_lx.py`，8 条全绿）

1. parse 统计：大/小真机文件音源分布与 opaque 三列表、`playHistory/downloadTasks` 原样；
2. 身份规则：kg 老格式原样 id + `lx_native_id`、`meta.id==0` 不写 `lx_num_id`、songmid 例外、未知源/无 id 走 opaque、quality 取最高档；
3. opaque 往返；4. render 外形（`origin:"created"` 枢纽新建标记等）；5. WebDAV 路由（PUT→GET 合并、兜底路径、`/d/pad/` 分桶隔离）；6. bypass_files 整文件原样；7. 幂等（revision 不变）。

> 联调口径：PUT body 是**整份文件**（缺席即删除），不是增量；`meta` 未知键不影响洛雪。
